# Water Glass

<img src="icon.png" alt="Water Glass" width="96" height="96">

An Android app made with Kiwimake.

Latest version: **1.0** (build 10), published 2026-11-20.

## Install

1. On your Android phone, open [waterglass.apk](https://github.com/maddada/anyapp-waterglass-releases/releases/latest/download/waterglass.apk).
2. Android asks you to allow installing apps from your browser: allow it, then tap Install.
3. From then on the app tells you when a new version is out. Tap the notification to update.
